## Requisitos

- Android Studio Ladybug ou mais recente
- JDK 17
- Android SDK 35

## Como executar

1. Abra esta pasta no Android Studio.
2. Aguarde a sincronização do Gradle.
3. Execute o aplicativo em um emulador ou dispositivo Android.

O relatório de produtos com desconto aparece no Logcat com a tag `CarrinhoLog`.

## Cenário implementado

- Notebook Dell Inspiron: 2 unidades, 5% de desconto
- Mouse sem fio: 1 unidade
- Teclado mecânico RGB: 1 unidade
- Subtotal bruto: R$ 7.437,80
- Descontos aplicados: R$ 349,90
- Total final: R$ 7.087,90
